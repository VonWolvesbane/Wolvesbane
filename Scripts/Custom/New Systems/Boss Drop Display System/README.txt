Wolvesbane UO - Boss Drop Display System v2.4
Install folder:
Custom/New Systems/BossDropDisplaySystem/

Commands:
[BossDropGump
[RemoveBossDropDisplay
[RefreshBossDropDisplay

v2.4 changes:
- Alternate drops now use vendor-style glass display-case art (0x2FEA).
- EACH conflicting/unwearable alternate item gets its own separate display case.
- Cases are placed east of the mannequin, one tile per alternate item.
- Pimp display order changed so PimpStick is equipped on the mannequin and PimpCane is routed to an alternate case when it conflicts.
- PimpHat remains the first registered head item; PimpsFace is displayed separately when it shares the same layer.
- Existing display-only ParachutePants layer correction is retained.
- Mannequins now track multiple linked cases and remove them automatically when deleted/refreshed.
- Backward compatibility retained for v2.3 single-case mannequin saves.

NOTE:
Refresh or replace previously placed displays to get the new multi-case layout.


v2.5 changes:
- Only the first BaseWeapon in a set is equipped on the mannequin.
- Every additional weapon goes into its own glass alternate-drop display, even if its Layer differs.
- Added [RefreshAllBossDropDisplays to rebuild every placed Boss Drop mannequin from the current registry while preserving location and direction.


v2.6 changes:
- One shared vendor-style glass Alternate Drops case per mannequin.
- All extra weapons and same-layer/conflicting items go into that one case.
- Mannequins are forced to face East when placed or refreshed.
- Shared display case is placed immediately east of its mannequin using the vendor-style glass case art.
- RefreshAllBossDropDisplays now also normalizes every display to the East-facing showroom layout.


v2.7 layout update:
- Mannequins face East.
- Shared Alternate Drops case is placed one tile directly south of its mannequin.
- Alternate Drops case uses the turned vendor-style display-case art (0x2FEB).
- [RefreshAllBossDropDisplays applies the new orientation/layout to existing displays.

v2.8 Evolution display update:
- Idium now has separate Unleveled and Fully Leveled (1001 Evolution Points) entries.
- Goliath now has separate Unleveled and Fully Leveled (1001 Evolution Points) entries.
- Maxed display items use each item's real EvolutionPoints property and ApplyGain() method, so displayed stats are generated by the original item scripts.
- Existing Idium/Goliath display keys remain assigned to the unleveled versions for refresh compatibility.

V2.9:
- Added Alley Oop (The Caveman) display from Custom/Tested/Caveman.
- Includes CavemanShirt, CavemanNeck, CavemanLoincloth, and CavemanClub.

v2.12 showroom additions:
- Boss information plaque north of each mannequin (NO boss location information).
- Player info gump with boss, set, category, race, piece count, and progression.
- Complete Set Stats viewer using reflection to total detectable numeric equipment bonuses.
- BossDropGump search/filter, Placed/Not Placed status, duplicate count, Info, and Go To.
- [AuditBossDropDisplays command and Audit button in the gump.
- [ValidateBossDropRegistry administrator command.
- [RefreshAllBossDropDisplays rebuilds plaques as well as mannequins/cases.


v2.12 additions:
- Wolvesbane Difficulty Rating (1-5) for boss entries with verified source stats.
- Safe decorative boss replicas using registered Body/Hue only; real boss classes are never instantiated.
- Boss replica is placed one tile west of the mannequin and faces East.
- Displays without a specific verified boss source show Not Rated and receive no fabricated statue.
- Global refresh rebuilds/repositions statues along with mannequin, plaque, and alternate case.


v2.13 changes:
- Removed decorative boss models/statues from all new and refreshed Boss Drop displays.
- Wolvesbane Difficulty Rating remains enabled and still uses BossDropBossData metadata.
- [RefreshBossDropDisplay and [RefreshAllBossDropDisplays automatically delete any legacy v2.12 statue linked to a mannequin.
- BossDropBossStatue.cs is intentionally retained only for backward-compatible loading/cleanup of worlds that were saved while v2.12 statues existed.
- Standard layout remains: plaque north, mannequin center facing East, shared Alternate Drops case south.

v2.15
- Restored Alternate Drops vendor-style display cases (0x2FEB). v2.14 accidentally applied the plaque ItemID to the cases.
- Plaques remain ItemID 19232.
- Added missing Wolvesbane Difficulty Ratings for Demon Lord, Revelation, Alien, Pimp, Pillager, Armor of Might/Titanious, and the Magi boss collection.
- Non-combat quest/NPC displays remain intentionally Not Rated.
