Install ALL files in this folder together.

  AeternumStoneLegs.cs
  AeternumStoneKilt.cs
  AeternumStoneWingArmor.cs
  AeternumCyclone.cs

Important:
- The weapons are NOT required for either five-piece armor set bonus.
- The five required armor slots remain Chest / Arms / Legs / Kilt / Wing Armor.
- Do NOT also install the old combined Wolvesbane_Gargoyle_Gear_v3.cs at the same time,
  or ServUO will see duplicate class definitions.
